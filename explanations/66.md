# Problem 66: Diophantine Equation

https://projecteuler.net/problem=66

**Answer:** 661 · **Solution:** `P66.java` · **Runtime:** ~0.01 s

## Problem

Consider quadratic Diophantine equations of the form:

```
x² − Dy² = 1
```

For example, when D = 13, the minimal solution in x is 649² − 13×180² = 1.

It can be assumed that there are no solutions in positive integers when D is square.

By finding minimal solutions in x for D = {2, 3, 5, 6, 7}, we obtain the following:

```
3² − 2×2² = 1
2² − 3×1² = 1
9² − 5×4² = 1
5² − 6×2² = 1
8² − 7×3² = 1
```

Hence, by considering minimal solutions in x for D ≤ 7, the largest x is obtained when D = 5.

Find the value of D ≤ 1000 in minimal solutions of x for which the largest value of x is obtained.

## In Plain Terms

For each D we want the smallest whole numbers x and y with x² − D·y² = 1. Searching x = 1, 2, 3, … is hopeless,
because for some D the smallest x has dozens of digits. But there's a classic shortcut: the fractions that best
approximate √D (from Problem 64's continued fractions) contain the answer. Walk through those fractions, and the
first one whose top and bottom satisfy the equation is the minimal solution.

## In Theory

This is **Pell's equation**. If x² − Dy² = 1, then x/y ≈ √D extremely closely, and every solution appears among
the **convergents** hₖ/kₖ of the continued fraction of √D. The fundamental (smallest) solution is the first
convergent that satisfies the equation — it occurs at the end of the first period (or the second, if the period
is odd).

Using the (m, d, a) recurrence from Problem 64 and the convergent recurrences

```
hₖ = aₖ·hₖ₋₁ + hₖ₋₂        kₖ = aₖ·kₖ₋₁ + kₖ₋₂
```

we stop at the first hₖ² − D·kₖ² = 1. For D = 661, the minimal x has 38 digits — the largest for D ≤ 1000.

## In Code

1. Skip square `i`. Otherwise set up m, d, a and the numerator/denominator pairs as `BigInteger`s.
2. Loop: advance the continued fraction one term and the convergent one step, until
   `numerator² − i × denominator² == 1`.
3. Keep the `i` with the largest numerator.

## Complexity

O(period of √D) steps per D, with big-number arithmetic on up to ~38-digit values. Space O(1) big numbers.
