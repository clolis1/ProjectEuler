# Problem 47: Distinct Primes Factors

https://projecteuler.net/problem=47

**Answer:** 134043 · **Solution:** `P47.java` · **Runtime:** ~0.11 s

## Problem

The first two consecutive numbers to have two distinct prime factors are:

```
14 = 2 × 7
15 = 3 × 5
```

The first three consecutive numbers to have three distinct prime factors are:

```
644 = 2² × 7 × 23
645 = 3 × 5 × 43
646 = 2 × 17 × 19
```

Find the first four consecutive integers to have four distinct prime factors each. What is the first of these
numbers?

## In Plain Terms

Count upward, breaking each number into its prime building blocks and counting how many *different* primes
it uses (2² × 7 counts as two: 2 and 7). Keep a streak counter: add one when a number has exactly four
different primes, reset to zero when it doesn't. When the streak hits four, the answer is the number where it
began.

## In Theory

The quantity is ω(n), the number of distinct prime factors. We want the first n with
ω(n) = ω(n+1) = ω(n+2) = ω(n+3) = 4. The run starts at 134043:

```
134043 = 3 × 7 × 13 × 491
134044 = 2² × 23 × 31 × 47
134045 = 5 × 17 × 19 × 83
134046 = 2 × 3² × 11 × 677
```

## In Code

1. For `i` from 2 upward, factor with `Primes.getPrimeFactors(i)`; the map's size is ω(i).
2. Increment `counter` when the size is 4, otherwise reset it.
3. When `counter` reaches 4, return `i − 3` (the code returns `i − 4` after its post-increment).

## Complexity

O(n√n) for trial-division factoring of every number up to n ≈ 134,000. Space O(log n) per factorization.

## Further Thoughts

A sieve that adds 1 to ω(m) for every multiple m of each prime computes ω for all numbers up to a bound in
O(n log log n).
