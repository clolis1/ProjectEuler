# Problem 25: 1000-digit Fibonacci Number

https://projecteuler.net/problem=25

**Answer:** 4782 · **Solution:** `P25.java` · **Runtime:** < 0.01 s

## Problem

The Fibonacci sequence is defined by the recurrence relation:

```
Fₙ = Fₙ₋₁ + Fₙ₋₂, where F₁ = 1 and F₂ = 1.
```

Hence the first 12 terms will be:

```
F1 = 1    F2 = 1    F3 = 2    F4 = 3    F5 = 5     F6 = 8
F7 = 13   F8 = 21   F9 = 34   F10 = 55  F11 = 89   F12 = 144
```

The 12th term, F12, is the first term to contain three digits.

What is the index of the first term in the Fibonacci sequence to contain 1000 digits?

## In Plain Terms

Fibonacci numbers grow by almost exactly the same factor every step — about 1.618, the "golden ratio". That
means their size follows a simple formula, and you can work out with logarithms (which count digits) exactly
which term first reaches 1000 digits, without computing any of the huge numbers themselves.

## In Theory

**Binet's formula** gives Fₙ = (φⁿ − ψⁿ)/√5 with φ = (1 + √5)/2 ≈ 1.618 and |ψ| < 1, so for large n

```
Fₙ ≈ φⁿ / √5
```

A number has at least 1000 digits when it's ≥ 10⁹⁹⁹. Taking log₁₀:

```
n·log₁₀ φ − log₁₀ √5 ≥ 999
n ≥ (999 + log₁₀ √5) / log₁₀ φ = (999 + 0.3495) / 0.20899 ≈ 4781.86
```

So the first such index is n = 4782.

## In Code

One line: `Math.round((n + log10(5)/2 − 1) / log10(φ))` with n = 1000 digits.

## Complexity

O(1). Space O(1).

## Further Thoughts

The code rounds to the *nearest* integer, but the inequality calls for rounding *up* (`Math.ceil`). Both
give 4782 here because the fraction is .86; a target whose fraction came out below .5 would be off by one.
The brute-force check — add `BigInteger`s until the length hits 1000 — is a good way to confirm it.
