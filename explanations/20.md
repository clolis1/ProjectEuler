# Problem 20: Factorial Digit Sum

https://projecteuler.net/problem=20

**Answer:** 648 · **Solution:** `P20.java` · **Runtime:** < 0.01 s

## Problem

n! means n × (n − 1) × ... × 3 × 2 × 1.

For example, 10! = 10 × 9 × ... × 3 × 2 × 1 = 3628800, and the sum of the digits in the number 10! is
3 + 6 + 2 + 8 + 8 + 0 + 0 = 27.

Find the sum of the digits in the number 100!.

## In Plain Terms

Multiply 1 × 2 × 3 × … × 100 — a 158-digit number — using Java's big-integer type, then add up its digits by
repeatedly peeling off the last digit (the remainder when dividing by 10) and dividing by 10.

## In Theory

100! has 158 digits, ending in 24 zeros (one for every factor of 5 in 1..100: ⌊100/5⌋ + ⌊100/25⌋ = 24).
The digit sum is computed with the identity

```
last digit = n mod 10,   remaining number = ⌊n / 10⌋
```

## In Code

1. `Arithmetic.bigFactorial(100)` multiplies recursively with `BigInteger`.
2. While the number is ≥ 10, add `num mod 10` and divide by 10; then add the final digit.

## Complexity

O(n) big multiplications for the factorial and O(d) big divisions for d digits — instant at this size.
Space O(d).
