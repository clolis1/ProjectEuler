# Problem 48: Self Powers

https://projecteuler.net/problem=48

**Answer:** 9110846700 · **Solution:** `P48.java` · **Runtime:** < 0.01 s

## Problem

The series, 1¹ + 2² + 3³ + ... + 10¹⁰ = 10405071317.

Find the last ten digits of the series, 1¹ + 2² + 3³ + ... + 1000¹⁰⁰⁰.

## In Plain Terms

1000¹⁰⁰⁰ has 3,001 digits, but we only care about the last ten digits of the total. When you multiply or add
numbers, the last ten digits of the result depend only on the last ten digits of what you started with. So
after every step, throw away everything except the last ten digits, and the numbers never get big.

## In Theory

This is **modular arithmetic** with modulus m = 10¹⁰:

```
(a × b) mod m = ((a mod m) × (b mod m)) mod m
(a + b) mod m = ((a mod m) + (b mod m)) mod m
```

So Σ iⁱ mod 10¹⁰ can be computed with small numbers throughout. A product of a value below 10¹⁰ and
i ≤ 1000 stays under 10¹³, well within a `long`.

## In Code

1. For each `i` from 1 to 1000, compute iⁱ mod 10¹⁰ by multiplying by `i` and reducing, `i` times.
2. Add it to `lastTen`, reducing mod 10¹⁰ again.

## Complexity

O(n²) multiplications — Σ i ≈ 500,000. Space O(1).

## Further Thoughts

**Fast exponentiation** (square-and-multiply) computes iⁱ mod m in O(log i) multiplications, making the
whole sum O(n log n). `BigInteger.modPow` does exactly that.
