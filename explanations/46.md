# Problem 46: Goldbach's Other Conjecture

https://projecteuler.net/problem=46

**Answer:** 5777 · **Solution:** `P46.java` · **Runtime:** ~0.04 s

## Problem

It was proposed by Christian Goldbach that every odd composite number can be written as the sum of a prime and
twice a square.

```
 9 =  7 + 2×1²
15 =  7 + 2×2²
21 =  3 + 2×3²
25 =  7 + 2×3²
27 = 19 + 2×2²
33 = 31 + 2×1²
```

It turns out that the conjecture was false.

What is the smallest odd composite that cannot be written as the sum of a prime and twice a square?

## In Plain Terms

Goldbach guessed that every odd number that isn't prime can be split into a prime plus twice a square number.
To find where he went wrong, count upward through odd numbers. For each one that isn't prime, try every prime
below it and see if what's left over is twice a square. The first number where nothing works disproves the
guess — that's 5777.

## In Theory

For odd composite n, we need a prime p and integer k ≥ 1 with n = p + 2k². Equivalently, for some square
s = k² < n/2, n − 2s must be prime.

Only two counterexamples are known: 5777 and 5993.

## In Code

1. Count up from 4, recording each perfect square in `squares` and each prime (trial division) in `primes`.
2. For each odd composite `i`, loop over known primes `l` and squares `m` (largest first), checking whether
   `l + 2m == i`; the square loop stops once the sum drops below `i`.
3. Return the first odd composite with no match.

## Complexity

O(π(n) × √n) checks per composite in the worst case — fine up to n ≈ 6,000. Space O(n / ln n).

## Further Thoughts

Looping over squares instead (k = 1, 2, … while 2k² < n) and testing n − 2k² for primality with a sieve
lookup is O(√n) per number.
