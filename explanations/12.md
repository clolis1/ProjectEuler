# Problem 12: Highly Divisible Triangular Number

https://projecteuler.net/problem=12

**Answer:** 76576500 · **Solution:** `P12.java` · **Runtime:** ~0.01 s

## Problem

The sequence of triangle numbers is generated by adding the natural numbers. So the 7th triangle
number would be 1 + 2 + 3 + 4 + 5 + 6 + 7 = 28. The first ten terms would be:

```
1, 3, 6, 10, 15, 21, 28, 36, 45, 55, ...
```

Let us list the factors of the first seven triangle numbers:

```
 1: 1
 3: 1, 3
 6: 1, 2, 3, 6
10: 1, 2, 5, 10
15: 1, 3, 5, 15
21: 1, 3, 7, 21
28: 1, 2, 4, 7, 14, 28
```

We can see that 28 is the first triangle number to have over five divisors.

What is the value of the first triangle number to have over five hundred divisors?

## In Plain Terms

A triangle number is how many bowling pins you need for a triangle with n rows. We walk through
them in order and, for each one, count how many whole numbers divide it evenly — stopping at the
first one with more than 500.

Counting divisors of a big number is slow, so the trick is to never look at the big number
directly. Every triangle number splits into two smaller pieces that share no common factors,
and you can count the divisors of each piece separately and multiply. Two small jobs instead
of one big one.

## In Theory

The nth triangle number is

```
T(n) = n(n+1)/2
```

Two facts make this fast:

1. **n and n+1 are coprime** — consecutive numbers share no factor greater than 1. Exactly one of them
   is even, so halving that one still leaves two coprime pieces:
   ```
   n even:  T(n) = (n/2) × (n+1)
   n odd:   T(n) = n × ((n+1)/2)
   ```
2. **The divisor-count function d(x) is multiplicative**: if gcd(a, b) = 1 then d(a × b) = d(a) × d(b).
   (Every divisor of ab splits uniquely into a divisor of a times a divisor of b.)

So d(T(n)) = d(piece₁) × d(piece₂), where both pieces are around n/2 instead of n²/2.

Example: T(7) = 28 = 7 × 4 → d(7) × d(4) = 2 × 3 = 6 divisors (1, 2, 4, 7, 14, 28). ✓

## In Code

1. Keep a running `triangle_number`, adding `i` each step so it equals T(i) without the formula.
2. Split by parity: if `i` is even, multiply `getNumDivisors(i/2)` by `getNumDivisors(i+1)`;
   otherwise `getNumDivisors(i)` by `getNumDivisors((i+1)/2)`.
3. `Divisors.getNumDivisors` trial-divides up to √x, adding 2 for each divisor pair and subtracting 1
   for perfect squares (where the pair is the same number twice).
4. Stop at the first total over 500 and print `triangle_number`.

The answer is T(12375): 12375 × 6188 = 76576500, with 576 divisors.

## Complexity

Each step costs O(√n) for the two divisor counts, so finding the answer at index N costs about
O(N^1.5) — here N = 12375, a few million operations. Space O(1).

## Further Thoughts

Counting divisors from the prime factorization — d(p₁^a₁ × p₂^a₂ × …) = (a₁+1)(a₂+1)… — is the
standard faster alternative to trial division for larger inputs.
