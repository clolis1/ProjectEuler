# Problem 27: Quadratic Primes

https://projecteuler.net/problem=27

**Answer:** -59231 · **Solution:** `P27.java` · **Runtime:** ~0.03 s

## Problem

Euler discovered the remarkable quadratic formula:

```
n² + n + 41
```

It turns out that the formula will produce 40 primes for the consecutive integer values 0 ≤ n ≤ 39. However,
when n = 40, 40² + 40 + 41 = 40(40 + 1) + 41 is divisible by 41, and certainly when n = 41, 41² + 41 + 41 is
clearly divisible by 41.

The incredible formula n² − 79n + 1601 was discovered, which produces 80 primes for the consecutive values
0 ≤ n ≤ 79. The product of the coefficients, −79 and 1601, is −126479.

Considering quadratics of the form:

```
n² + an + b, where |a| < 1000 and |b| ≤ 1000
```

where |n| is the modulus/absolute value of n, e.g. |11| = 11 and |−4| = 4.

Find the product of the coefficients, a and b, for the quadratic expression that produces the maximum number
of primes for consecutive values of n, starting with n = 0.

## In Plain Terms

We're hunting for a formula n² + an + b that spits out primes for as long as possible as n counts up from 0.
Rather than test all four million (a, b) combinations, rule most out first. Plug in n = 0 and you get b, so b
itself must be prime. Plug in n = 1 and you get 1 + a + b; for that to be an odd prime, a has to be odd.
That leaves about 170 values of b and 1,000 of a — easy to try them all.

## In Theory

- n = 0 gives b, so **b must be a (positive) prime** — fewer than 170 candidates.
- For b an odd prime, n = 1 gives 1 + a + b, which is even (and > 2) unless **a is odd**.

For each surviving pair, count consecutive n giving primes. The best is a = −61, b = 971, which produces
71 primes (n = 0..70). The product is −61 × 971 = −59231.

## In Code

1. `primes` = all primes below 1000 (the b candidates).
2. For every odd `a` from 999 down to −999 and every prime `b`: count n upward while
   `Primes.isPrime(n² + a·n + b)`; keep the (a, b) with the longest run.
3. A second pass repeats this for −b — but n = 0 gives a negative number, which is never prime, so that pass
   can never win. It can be removed.

## Complexity

O(A × B × L × √v): A values of a, B primes b, run length L, and a primality test on values up to v.
In practice it's about 170,000 short runs. Space O(B).
