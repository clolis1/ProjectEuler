# Problem 22: Names Scores

https://projecteuler.net/problem=22

**Answer:** 871198282 · **Solution:** `P22.java` · **Runtime:** ~0.03 s

## Problem

Using names.txt (`data/p022_names.txt`), a 46K text file containing over five-thousand first names, begin by
sorting it into alphabetical order. Then working out the alphabetical value for each name, multiply this value
by its alphabetical position in the list to obtain a name score.

For example, when the list is sorted into alphabetical order, COLIN, which is worth 3 + 15 + 12 + 9 + 14 = 53,
is the 938th name in the list. So, COLIN would obtain a score of 938 × 53 = 49714.

What is the total of all the name scores in the file?

## In Plain Terms

Alphabetize the list of names. Give each letter a value (A = 1, B = 2, …, Z = 26), add up the letters in each
name, multiply by the name's place in the list, and total everything. It's mostly about reading the file
correctly and sorting.

## In Theory

Straightforward: one sort, then a weighted sum

```
total = Σ (position i) × (letter value of name i)
```

Letter values come from character codes: 'A' is 65, so value = code − 64.

## In Code

1. Read the file with `Resources.scanner`, splitting on commas and stripping the quotes.
2. `Collections.sort` the names.
3. For each name at index `i`, add `(i + 1) × Σ(c − 64)` to a `long` total.

## Complexity

O(n log n) for the sort (n ≈ 5,000), plus O(total characters) for scoring. Space O(n).
