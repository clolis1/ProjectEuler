# Problem 36: Double-base Palindromes

https://projecteuler.net/problem=36

**Answer:** 872187 · **Solution:** `P36.java` · **Runtime:** ~0.02 s

## Problem

The decimal number, 585 = 1001001001₂ (binary), is palindromic in both bases.

Find the sum of all numbers, less than one million, which are palindromic in base 10 and base 2.

(Please note that the palindromic number, in either base, may not include leading zeros.)

## In Plain Terms

Check every number under a million: does it read the same forwards and backwards in ordinary decimal, and
also when written in binary (ones and zeros)? Add up the ones that pass both tests. Java can write a number
in binary for us, so each check is just comparing a string with its reverse.

## In Theory

A brute-force scan of 10⁶ numbers is cheap. One observation halves it: a binary palindrome can't end in 0
(it would have to start with 0), so every answer is **odd**.

## In Code

For each `i` below 1,000,000, test `Digits.isPalindrome` on both `Integer.toString(i)` and
`Integer.toBinaryString(i)`; if both pass, add `i`.

## Complexity

O(n log n) — n numbers, each with O(log n) digits to compare. Space O(log n).

## Further Thoughts

Generating palindromes directly is far faster: there are only about 2,000 decimal palindromes below a million
(build them from their first half), and each needs just one binary check.
