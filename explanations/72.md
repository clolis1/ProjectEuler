# Problem 72: Counting Fractions

https://projecteuler.net/problem=72

**Answer:** 303963552391 · **Solution:** `P72.java` · **Runtime:** ~0.8 s

## Problem

Consider the fraction, n/d, where n and d are positive integers. If n < d and HCF(n, d) = 1, it is called a
reduced proper fraction.

If we list the set of reduced proper fractions for d ≤ 8 in ascending order of size, we get:

```
1/8, 1/7, 1/6, 1/5, 1/4, 2/7, 1/3, 3/8, 2/5, 3/7, 1/2, 4/7, 3/5, 5/8, 2/3, 5/7, 3/4, 4/5, 5/6, 6/7, 7/8
```

It can be seen that there are 21 elements in this set.

How many elements would be contained in the set of reduced proper fractions for d ≤ 1,000,000?

## In Plain Terms

For a given bottom number d, the fractions n/d that can't be simplified are exactly those where n shares no
factor with d. Counting those is what Euler's totient φ(d) does. So the answer is just φ(2) + φ(3) + … + φ(10⁶).

## In Theory

The reduced proper fractions with denominator d are n/d with 1 ≤ n < d and gcd(n, d) = 1 — there are φ(d) of
them. So

```
|set| = Σ φ(d)  for d = 2 .. 1,000,000
```

This is the length of the Farey sequence Fₙ minus its two endpoints (0/1 and 1/1). The result, about 3.04 × 10¹¹,
needs a `long`; it's close to the asymptotic 3n²/π².

## In Code

Loop `i` from 2 to 1,000,000 and add `Primes.eulersTotient(i)` (written as `i − (i − φ)`). Each totient uses
trial division.

## Complexity

O(n√n) for trial-division totients. Space O(1).

## Further Thoughts

A **totient sieve** computes every φ(d) up to n in O(n log log n): start with φ[d] = d, and for each prime p
multiply every multiple's entry by (1 − 1/p).
