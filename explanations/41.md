# Problem 41: Pandigital Prime

https://projecteuler.net/problem=41

**Answer:** 7652413 · **Solution:** `P41.java` · **Runtime:** ~0.06 s

## Problem

We shall say that an n-digit number is pandigital if it makes use of all the digits 1 to n exactly once. For
example, 2143 is a 4-digit pandigital and is also prime.

What is the largest n-digit pandigital prime that exists?

## In Plain Terms

List every number that uses the digits 1 to n exactly once, from the largest down, and stop at the first
prime. There's a neat shortcut: a number is divisible by 3 whenever its digits add up to a multiple of 3. The
digits 1–9 add to 45 and 1–8 add to 36 — both multiples of 3 — so no 9- or 8-digit pandigital can be prime,
and the answer must have 7 digits or fewer.

## In Theory

**Divisibility by 3**: n ≡ (digit sum) mod 3. The digit sum of a 1-to-n pandigital is n(n+1)/2:

```
n:          4   5   6   7   8   9
digit sum: 10  15  21  28  36  45
÷ 3?        no yes yes  no yes yes
```

So only 4- and 7-digit pandigitals can be prime. Scanning 7-digit permutations from largest to smallest, the
first prime is 7652413.

## In Code

1. Build one list of all permutations of "1", "12", …, "123456789" with `Lexography.sortedPermutations`,
   each length in ascending order.
2. Walk the list backwards (largest 9-digit first) and return the first value `Primes.isPrime` accepts.

## Complexity

The list holds Σ n! ≈ 410,000 strings, and the backward scan tests all 9! + 8! ≈ 400,000 of the 9- and 8-digit
ones (none prime) before reaching the 7-digit block. Space O(Σ n!).

## Further Thoughts

Using the divisibility rule, the search could start directly at the 7-digit permutations — about 5,000
candidates in descending order.
