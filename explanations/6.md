# Problem 6: Sum Square Difference

https://projecteuler.net/problem=6

**Answer:** 25164150 · **Solution:** `P6.java` · **Runtime:** < 0.01 s

## Problem

The sum of the squares of the first ten natural numbers is

```
1² + 2² + … + 10² = 385
```

The square of the sum of the first ten natural numbers is

```
(1 + 2 + … + 10)² = 55² = 3025
```

Hence the difference between the sum of the squares of the first ten natural numbers and the square of
the sum is 3025 − 385 = 2640.

Find the difference between the sum of the squares of the first one hundred natural numbers and the
square of the sum.

## In Plain Terms

Two ways of combining the numbers 1 to 100: square each one and add them up, or add them all up and then
square the total. The second is much bigger, because squaring a total also counts every pair of numbers
multiplied together. The question just asks for the gap between the two.

## In Theory

Both have well-known closed forms:

```
1 + 2 + … + n      = n(n+1)/2           → for n = 100: 5050,  squared = 25502500
1² + 2² + … + n²   = n(n+1)(2n+1)/6     → for n = 100: 338350

25502500 − 338350 = 25164150
```

The difference is exactly twice the sum of all products i × j with i < j — the "cross terms" you get when
you expand (1 + 2 + … + n)².

## In Code

1. One loop adds up `i²` for i = 1..100.
2. A second loop adds up `i`, then the total is squared.
3. Return the difference (computed in `double`, cast to `int`; both values are exact at this size).

## Complexity

O(n) with the loops, O(1) with the formulas. Space O(1).
