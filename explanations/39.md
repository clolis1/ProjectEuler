# Problem 39: Integer Right Triangles

https://projecteuler.net/problem=39

**Answer:** 840 · **Solution:** `P39.java` · **Runtime:** ~0.06 s

## Problem

If p is the perimeter of a right angle triangle with integral length sides, {a, b, c}, there are exactly three
solutions for p = 120.

```
{20,48,52}, {24,45,51}, {30,40,50}
```

For which value of p ≤ 1000, is the number of solutions maximised?

## In Plain Terms

For every perimeter up to 1000, count how many right triangles with whole-number sides have exactly that
perimeter. Fix the two shorter sides, and the third is whatever's left over — then just check whether
Pythagoras holds. The perimeter with the most triangles wins.

## In Theory

For perimeter p and sides x ≤ y < z with z = p − x − y, we need x² + y² = z². Ordering the sides gives bounds:
x ≤ p/3 and y ≤ (p − x)/2.

Two quick facts: p must be **even** (in a primitive triple a + b + c = 2m(m + n), and scaling keeps it even),
and the most solutions go to perimeters with many divisors. 840 = 2³ × 3 × 5 × 7 has 8 solutions.

## In Code

1. For every `i` from 12 to 1000, loop `x` up to `i/3` and `y` from `x` up to `(i − x)/2`, set `z = i − x − y`,
   and count it if `x² + y² = z²`.
2. Return the perimeter with the highest count.

## Complexity

Σ p² / 12 over p ≤ N — about N³/36 ≈ 28 million checks for N = 1000. Space O(N).

## Further Thoughts

Generating triples with Euclid's formula (as in Problem 9) and adding each multiple's perimeter to a counter
is O(N log N). Restricting to even p alone halves the current work.
