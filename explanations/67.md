# Problem 67: Maximum Path Sum II

https://projecteuler.net/problem=67

**Answer:** 7273 · **Solution:** `P67.java` · **Runtime:** < 0.01 s

## Problem

By starting at the top of the triangle below and moving to adjacent numbers on the row below, the maximum total
from top to bottom is 23.

```
   3
  7 4
 2 4 6
8 5 9 3
```

That is, 3 + 7 + 4 + 9 = 23.

Find the maximum total from top to bottom in triangle.txt (`data/p067_triangle.txt`), a 15K text file containing
a triangle with one-hundred rows.

NOTE: This is a much more difficult version of Problem 18. It is not possible to try every route to solve this
problem, as there are 2⁹⁹ altogether! If you could check one trillion (10¹²) routes every second it would take
over twenty billion years to check them all. There is an efficient algorithm to solve it. ;o)

## In Plain Terms

Exactly the same as Problem 18, just bigger: go row by row and write down, for each number, the best total you
could have when you reach it. That's about 5,000 small additions instead of 2⁹⁹ routes — the difference between
instant and longer than the age of the universe.

## In Theory

**Dynamic programming** — see Problem 18. The key property is **optimal substructure**: the best path to any cell
extends the best path to one of its two parents, so each cell needs only the two values above it.

## In Code

1. Read the triangle from the file with `Resources.scanner` into a 100×100 grid.
2. Run the same in-place row update as Problem 18 on a single `max_sums` array.
3. Return the largest value in the last row.

## Complexity

O(n²) for n = 100 rows — 5,050 cells. Space O(n).
