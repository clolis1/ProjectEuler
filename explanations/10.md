# Problem 10: Summation of Primes

https://projecteuler.net/problem=10

**Answer:** 142913828922 · **Solution:** `P10.java` · **Runtime:** ~0.14 s

## Problem

The sum of the primes below 10 is 2 + 3 + 5 + 7 = 17.

Find the sum of all the primes below two million.

## In Plain Terms

List every prime below two million and add them up. The listing works the same way as Problem 7: test each
odd number against the primes found so far, stopping at its square root. The only twist is the size of the
total — over 140 billion — which is too big for an ordinary integer, so it's added up in a larger number type.

## In Theory

There are π(2,000,000) = 148,933 primes below two million. Each candidate n is prime iff no prime ≤ √n
divides it (see Problem 7).

The sum is about 1.4 × 10¹¹, which overflows a 32-bit int (max ≈ 2.1 × 10⁹), so it must be accumulated
in a 64-bit `long`.

## In Code

1. `Primes.getPrimesUpUntil(2_000_000)` seeds the list with 2 and 3, then tests odd numbers from 5
   upward by trial division against the primes already found, up to √n.
2. `P10` adds the list up as `long` values.

## Complexity

Roughly O(n√n / ln n) for trial division across all candidates. Space O(n / ln n) for the list of primes.

## Further Thoughts

A **Sieve of Eratosthenes** — cross off multiples of each prime in a boolean array — finds all primes
below n in O(n log log n) and is the standard tool for "all primes below N" problems.
