# Problem 75: Singular Integer Right Triangles

https://projecteuler.net/problem=75

**Answer:** 161667 · **Solution:** `P75.java` · **Runtime:** ~0.32 s

## Problem

It turns out that 12 cm is the smallest length of wire that can be bent to form an integer sided right angle
triangle in exactly one way, but there are many more examples.

```
12 cm: (3,4,5)
24 cm: (6,8,10)
30 cm: (5,12,13)
36 cm: (9,12,15)
40 cm: (8,15,17)
48 cm: (12,16,20)
```

In contrast, some lengths of wire, like 20 cm, cannot be bent to form an integer sided right angle triangle, and
other lengths allow more than one solution to be found; for example, using 120 cm it is possible to form exactly
three different integer sided right angle triangles.

```
120 cm: (30,40,50), (20,48,52), (24,45,51)
```

Given that L is the length of the wire, for how many values of L ≤ 1,500,000 can exactly one integer sided right
angle triangle be formed?

## In Plain Terms

Generate every "basic" whole-number right triangle (like 3-4-5) with a recipe, and tally its perimeter. Then
every scaled-up copy (6-8-10, 9-12-15, …) has a perimeter that's a multiple of the basic one, so tally those too.
At the end, count the perimeters that were tallied exactly once.

## In Theory

**Euclid's formula** generates every primitive triple exactly once from integers m > n > 0 that are coprime and
of opposite parity:

```
a = m² − n²,   b = 2mn,   c = m² + n²,   perimeter = 2m(m + n)
```

Every triple is k × (a primitive one), so its perimeter is a multiple of a primitive perimeter. Count, for each
L ≤ 1.5 × 10⁶, how many (primitive perimeter p, multiplier k) pairs give kp = L, and count the L's with exactly one.

## In Code

1. Loop `n` upward and `m = n+1, n+3, n+5, …` (opposite parity) while the perimeter fits; for coprime `(m, n)`
   (`Divisors.isRelativelyPrime`), tally the perimeter in `perimeters`.
2. For each primitive perimeter `k`, add 1 at every multiple k, 2k, 3k, … ≤ 1,500,000 in `updated_perimeters`
   (the first visit copies the primitive tally).
3. Count the entries equal to 1.

## Complexity

O(L log L) — about √L primitive triples, each spreading over L/p multiples. Space O(L) for the maps.

## Further Thoughts

A plain `int[1_500_001]` array is faster and simpler than the two hash maps: add 1 at every multiple of each
primitive perimeter, then count the 1s.
