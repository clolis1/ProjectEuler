# Problem 57: Square Root Convergents

https://projecteuler.net/problem=57

**Answer:** 153 · **Solution:** `P57.java` · **Runtime:** ~0.03 s

## Problem

It is possible to show that the square root of two can be expressed as an infinite continued fraction.

```
√2 = 1 + 1/(2 + 1/(2 + 1/(2 + ...)))
```

By expanding this for the first four iterations, we get:

```
1 + 1/2                         = 3/2   = 1.5
1 + 1/(2 + 1/2)                 = 7/5   = 1.4
1 + 1/(2 + 1/(2 + 1/2))         = 17/12 = 1.41666...
1 + 1/(2 + 1/(2 + 1/(2 + 1/2))) = 41/29 = 1.41379...
```

The next three expansions are 99/70, 239/169, and 577/408, but the eighth expansion, 1393/985, is the first
example where the number of digits in the numerator exceeds the number of digits in the denominator.

In the first one-thousand expansions, how many fractions contain a numerator with more digits than the
denominator?

## In Plain Terms

The fractions 3/2, 7/5, 17/12, 41/29, … get closer and closer to √2, and each one comes from the previous one
by a simple rule. Generate the first thousand, and count how often the top number has more digits than the
bottom one. The numbers get very large (hundreds of digits), so they're stored as big integers.

## In Theory

If one expansion is n/d, the next is

```
1 + 1/(1 + n/d)  =  (n + 2d) / (n + d)
```

So n' = n + 2d and d' = n + d. Since n/d → √2 ≈ 1.414, the numerator has an extra digit exactly when n crosses
a power of 10 before d does — roughly whenever the leading digits of d fall between 1/√2 × 10ᵏ and 10ᵏ. That
happens a bit more than 15% of the time, giving 153 of 1000.

## In Code

1. Track `current_numerator`, `current_denominator` and `previous_denominator` as `BigInteger`s.
2. The denominators follow d' = 2d + d_prev (the Pell numbers), and the numerator grows by twice the old
   denominator — equivalent to the n' = n + 2d, d' = n + d recurrence.
3. After each step, compare the decimal string lengths and count when the numerator's is longer.

## Complexity

O(k × d) for k expansions with d-digit additions (d grows to ~380). Space O(d).
