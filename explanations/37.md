# Problem 37: Truncatable Primes

https://projecteuler.net/problem=37

**Answer:** 748317 · **Solution:** `P37.java` · **Runtime:** ~0.09 s

## Problem

The number 3797 has an interesting property. Being prime itself, it is possible to continuously remove digits
from left to right, and remain prime at each stage: 3797, 797, 97, and 7. Similarly we can work from right to
left: 3797, 379, 37, and 3.

Find the sum of the only eleven primes that are both truncatable from left to right and right to left.

NOTE: 2, 3, 5, and 7 are not considered to be truncatable primes.

## In Plain Terms

Generate primes in order, and for each one, chop digits off the right end one at a time (3797 → 379 → 37 → 3),
then off the left end (3797 → 797 → 97 → 7), checking that every piece is prime. Because we generate primes
in increasing order, every smaller piece has already been checked for primality, so each test is just a lookup.
The problem promises there are exactly eleven, so stop when we've found them.

## In Theory

- Truncating from the right is integer division by 10: n → ⌊n/10⌋.
- Truncating from the left is taking a remainder: n → n mod 10ᵏ.

All pieces are smaller than n, so if primes are generated in increasing order, they're already known.

The eleven are 23, 37, 53, 73, 313, 317, 373, 797, 3137, 3797 and 739397. (It's known that there are no more:
only finitely many primes are right-truncatable — 83 of them — so the search is guaranteed to end.)

## In Code

1. Grow a `TreeSet` of primes by trial division, testing odd `counter` values from 5 upward.
2. For each new prime with at least two digits: divide by 10 repeatedly and check each result is in the set;
   then take `z mod 10^k` for decreasing k and check those too.
3. Add the prime to `sum` if both directions pass; stop once eleven are found.

## Complexity

Dominated by generating primes up to 739,397 by trial division, roughly O(n√n / ln n). Space O(π(n)).

## Further Thoughts

Building right-truncatable primes **forward** is much faster: start from 2, 3, 5, 7 and repeatedly append
a digit 1, 3, 7 or 9, keeping only primes. That generates all 83 right-truncatable primes; then filter for
left-truncatability.
