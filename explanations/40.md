# Problem 40: Champernowne's Constant

https://projecteuler.net/problem=40

**Answer:** 210 · **Solution:** `P40.java` · **Runtime:** ~0.03 s

## Problem

An irrational decimal fraction is created by concatenating the positive integers:

```
0.123456789101112131415161718192021...
```

It can be seen that the 12th digit of the fractional part is 1.

If dₙ represents the nth digit of the fractional part, find the value of the following expression.

```
d₁ × d₁₀ × d₁₀₀ × d₁₀₀₀ × d₁₀₀₀₀ × d₁₀₀₀₀₀ × d₁₀₀₀₀₀₀
```

## In Plain Terms

Write 1, 2, 3, … one after another with no gaps: 123456789101112… We need the digits at positions 1, 10,
100, and so on up to a million. Count along, number by number, keeping track of how many digits we've written.
Whenever the count crosses one of the target positions, look back inside the current number to find the digit
that landed exactly there.

## In Theory

The digits are 1, 1, 5, 3, 7, 2, 1, so the product is 210.

They can also be found directly by counting digits in blocks: 9 one-digit numbers fill positions 1–9,
90 two-digit numbers fill 10–189, 900 three-digit numbers fill 190–2889, and so on. For position k, skip whole
blocks, then

```
number = first number in the block + ⌊(k − block start) / digits per number⌋
digit  = position (k − block start) mod (digits per number) within that number
```

## In Code

1. For `i` from 1 up, add its digit count to `index` (the position of its last digit).
2. When `index` reaches the next power of ten, step back `offset` digits from the end of `i` to find the
   digit at exactly that position, multiply it into `product`, and move to the next power of ten.

## Complexity

O(n) — counting up to about 185,000 numbers to pass position 10⁶. Space O(1).
