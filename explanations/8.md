Find the thirteen adjacent digits in the 1000-digit number that have the greatest product. What is the
value of this product?

## In Plain Terms

Slide a window 13 digits wide along the big number, multiply the digits inside it, and remember the
biggest result. One shortcut: any window containing a 0 multiplies out to 0, so you can jump straight
past every zero.

## In Theory

This is a **sliding window** search over 1000 − 13 + 1 = 988 positions. Two details matter:

- **Zeros** make the product 0, so windows containing them can be discarded outright.
- **Overflow**: 9¹³ ≈ 2.5 × 10¹² is far beyond a 32-bit int (~2.1 × 10⁹), so products need a 64-bit `long`.

## In Code

1. Walk a shrinking copy of the input string:
   - if there's a `0` within the first 13 characters, chop the string just past that zero;
   - otherwise record the first 13 characters as a candidate window and drop one character.
2. Multiply out the digits of every candidate window (as a `long`) and keep the maximum.

## Complexity

O(n × k) for n digits and window size k — each candidate window is multiplied from scratch.
Space O(n × k) for the stored windows.

## Further Thoughts

Windows could be updated in O(1) each by dividing out the digit leaving and multiplying in the one
entering (safe here since zero-containing windows are skipped), giving O(n) overall.
