# Problem 15: Lattice Paths

https://projecteuler.net/problem=15

**Answer:** 137846528820 · **Solution:** `P15.java` · **Runtime:** < 0.01 s

## Problem

Starting in the top left corner of a 2×2 grid, and only being able to move to the right and down, there are
exactly 6 routes to the bottom right corner.

```
RRDD   RDRD   RDDR   DRRD   DRDR   DDRR
```

How many such routes are there through a 20×20 grid?

## In Plain Terms

Every route across a 20×20 grid is exactly 20 steps right and 20 steps down — 40 steps in all. The only
thing that differs between routes is *which* of the 40 steps are the "right" ones. So the question is really:
how many ways can you choose 20 positions out of 40? That's a standard counting problem with a known formula.

## In Theory

A route is a string of 20 R's and 20 D's, and every such string is a valid route. The number of these is the
**binomial coefficient**

```
C(40, 20) = 40! / (20! × 20!) = 137846528820
```

(The 2×2 example: C(4, 2) = 4!/(2!·2!) = 6.)

40! has 48 digits, so the code avoids computing it directly.

## In Code

1. Factor every number 1..40 with `Primes.getPrimeFactors` and add the exponents into a numerator map;
   numbers 1..20 are added to the denominator map twice (once per 20!).
2. Subtract the denominator's exponents from the numerator's — the "cancelling" step.
3. Multiply out what's left: Π p^exponent. Everything stays within a `long`.

## Complexity

O(n√n) to factor the numbers up to 2n by trial division. Space O(π(2n)) for the exponent maps.

## Further Thoughts

The multiplicative formula avoids factoring entirely and never overflows at this size:

```
result = 1
for i in 1..20:  result = result × (20 + i) / i     (each step is an exact integer)
```
