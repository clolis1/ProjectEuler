# Problem 61: Cyclical Figurate Numbers

https://projecteuler.net/problem=61

**Answer:** 28684 · **Solution:** `P61.java` · **Runtime:** ~0.03 s

## Problem

Triangle, square, pentagonal, hexagonal, heptagonal, and octagonal numbers are all figurate (polygonal) numbers
and are generated by the following formulae:

```
Triangle     P3,n = n(n+1)/2    1, 3, 6, 10, 15, ...
Square       P4,n = n²          1, 4, 9, 16, 25, ...
Pentagonal   P5,n = n(3n−1)/2   1, 5, 12, 22, 35, ...
Hexagonal    P6,n = n(2n−1)     1, 6, 15, 28, 45, ...
Heptagonal   P7,n = n(5n−3)/2   1, 7, 18, 34, 55, ...
Octagonal    P8,n = n(3n−2)     1, 8, 21, 40, 65, ...
```

The ordered set of three 4-digit numbers: 8128, 2882, 8281, has three interesting properties.

1. The set is cyclic, in that the last two digits of each number is the first two digits of the next number
   (including the last number with the first).
2. Each polygonal type: triangle (P3,127 = 8128), square (P4,91 = 8281), and pentagonal (P5,44 = 2882), is
   represented by a different number in the set.
3. This is the only set of 4-digit numbers with this property.

Find the sum of the only ordered set of six cyclic 4-digit numbers for which each polygonal type: triangle,
square, pentagonal, hexagonal, heptagonal, and octagonal, is represented by a different number in the set.

## In Plain Terms

Think of it as a word-chain game with numbers: each four-digit number's last two digits must be the next
number's first two, and the chain has to loop back to the start. On top of that, the six numbers must come from
six different "shape" families — one triangle number, one square, and so on. Start from each triangle number,
try every order of the other five families, and follow the chain.

## In Theory

Every family has only a few dozen 4-digit members (from 40 octagonal to 96 triangle), and each link is forced
by two digits, so a **depth-first search** with backtracking is tiny. Since the cycle must contain a triangle
number, we can fix it as the starting point without losing any solutions; then try all 5! = 120 orders of the
remaining families.

The set is 8128 (hexagonal), 2882 (pentagonal), 8256 (triangle), 5625 (square), 2512 (heptagonal) and
1281 (octagonal) — sum 28684.

## In Code

1. Fill `nums[type][value]` lookup tables for the six families up to 5 digits.
2. For each 4-digit triangle number `i` (whose last two digits don't start with 0), and each ordering of the
   other five types (`Lexography.sortedPermutations("12345")`):
3. Six nested loops each try the 90 numbers starting with the previous number's last two digits, keep those in
   the required family, and finally check the last number links back to `i`.

## Complexity

At most 96 × 120 × 90⁵ in theory, but the family checks prune almost every branch, so only a few thousand
partial chains are explored. Space O(10⁵) for the lookup tables.

## Further Thoughts

The search doesn't check that the six numbers are distinct; a number belonging to two families (like 8128,
which is both triangular and hexagonal) could in principle fill two slots. It doesn't happen in the answer, but
a set of used numbers would make the search airtight.
