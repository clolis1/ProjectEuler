# Problem 63: Powerful Digit Counts

https://projecteuler.net/problem=63

**Answer:** 49 · **Solution:** `P63.java` · **Runtime:** < 0.01 s

## Problem

The 5-digit number, 16807 = 7⁵, is also a fifth power. Similarly, the 9-digit number, 134217728 = 8⁹, is a ninth
power.

How many n-digit positive integers exist which are also an nth power?

## In Plain Terms

We want numbers like 16807, which has 5 digits and is something to the 5th power. The base can't be 10 or more,
because 10ⁿ already has n + 1 digits. So the base is 1 through 9. For each base, raise it to higher and higher
powers and count the ones whose digit count matches the power. Smaller bases fall behind quickly, so this ends
fast.

## In Theory

aⁿ has n digits iff 10ⁿ⁻¹ ≤ aⁿ < 10ⁿ.

- The right side forces **a < 10**.
- The left side, taking logs: n − 1 ≤ n log₁₀ a, so **n ≤ 1 / (1 − log₁₀ a)**.

So each base a from 1 to 9 contributes ⌊1 / (1 − log₁₀ a)⌋ values of n:

```
a:  1  2  3  4  5  6  7   8   9
n:  1  1  1  2  3  4  6  10  21    → total 49
```

## In Code

For each base `i` from 1 to 9, multiply up powers `j = i, i², i³, …` as `BigInteger`s, count when the digit
length equals the exponent, and stop once the length falls behind the exponent.

## Complexity

O(Σ nₐ) — about 50 powers. Space O(1). (Or O(1) with the closed form.)
