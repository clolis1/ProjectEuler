# Problem 42: Coded Triangle Numbers

https://projecteuler.net/problem=42

**Answer:** 162 · **Solution:** `P42.java` · **Runtime:** < 0.01 s

## Problem

The nth term of the sequence of triangle numbers is given by, tₙ = ½n(n+1); so the first ten triangle numbers
are:

```
1, 3, 6, 10, 15, 21, 28, 36, 45, 55, ...
```

By converting each letter in a word to a number corresponding to its alphabetical position and adding these
values we form a word value. For example, the word value for SKY is 19 + 11 + 25 = 55 = t₁₀. If the word value
is a triangle number then we shall call the word a triangle word.

Using words.txt (`data/p042_words.txt`), a 16K text file containing nearly two-thousand common English words,
how many are triangle words?

## In Plain Terms

Score each word by adding up its letters (A = 1 … Z = 26), then check whether that score is a triangle
number — 1, 3, 6, 10, 15, … — the number of dots you can arrange in a triangle. Keep a growing list of
triangle numbers, extend it whenever a word's score is bigger than anything on it, and count the matches.

## In Theory

x is triangular iff x = n(n+1)/2 for some integer n, which rearranges to

```
8x + 1 is a perfect square
```

Either test works; word values are small (under ~200), so a short lookup list of triangle numbers is
just as easy.

## In Code

1. Read the words with `Resources.scanner`, splitting on commas and stripping quotes.
2. For each word, compute its value (`c − 64` per letter).
3. Extend the `TreeSet` of triangle numbers until it reaches the value, then count the word if the value is in it.

## Complexity

O(total letters) for scoring, plus O(log t) per lookup. Space O(t) for t triangle numbers (about 20).
