# Problem 77: Prime Summations

https://projecteuler.net/problem=77

**Answer:** 71 · **Solution:** `P77.java` · **Runtime:** < 0.01 s

## Problem

It is possible to write ten as the sum of primes in exactly five different ways:

```
7 + 3
5 + 5
5 + 3 + 2
3 + 3 + 2 + 2
2 + 2 + 2 + 2 + 2
```

What is the first value which can be written as the sum of primes in over five thousand different ways?

## In Plain Terms

Same coin-counting idea as Problems 31 and 76, but now the only "coins" allowed are primes: 2, 3, 5, 7, …. For
each target number, count the ways to build it from prime coins, and stop at the first target with more than
5,000 ways. The count grows quickly, so the answer is small: 71.

## In Theory

These are **prime partitions**. The same dynamic programming applies with parts restricted to primes:

```
ways[0] = 1
for each prime p:
    for t = p .. target:  ways[t] += ways[t − p]
```

The number of prime partitions grows roughly like exp(c·√(n / log n)), so it passes 5,000 early.

## In Code

1. For `target = 2, 3, …`, run the DP above with primes below 1000 (`Primes.getPrimesUpUntil`).
2. Return the first target whose count exceeds 5,000.

## Complexity

O(T × π(T) × T) if the table is rebuilt per target — trivial for T = 71. Space O(T).

## Further Thoughts

Building the table once up to a generous bound (say 100) and scanning for the first entry over 5,000 avoids
recomputing it for every target.
