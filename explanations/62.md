# Problem 62: Cubic Permutations

https://projecteuler.net/problem=62

**Answer:** 127035954683 · **Solution:** `P62.java` · **Runtime:** < 0.01 s

## Problem

The cube, 41063625 (345³), can be permuted to produce two other cubes: 56623104 (384³) and 66430125 (405³). In
fact, 41063625 is the smallest cube which has exactly three permutations of its digits which are also cube.

Find the smallest cube for which exactly five permutations of its digits are cube.

## In Plain Terms

Compute cubes in order, and file each one under its digits sorted — 41063625 goes in the drawer labelled
"01234566". Cubes that are rearrangements of each other land in the same drawer. As soon as a drawer holds five
cubes, the first cube in it is the answer.

## In Theory

The sorted-digit string is a **canonical signature** for "permutation of each other" (as in Problem 49). Hashing
by signature groups all permutations in O(1) per cube.

The answer's group is 5027³, 7061³, 7202³, 8288³, 8384³ → the smallest is 5027³ = 127035954683.

## In Code

1. For n = 1, 2, …, compute n³ and its sorted-digit signature.
2. Append the cube to `cubes[signature]`; when a list reaches five entries, return its first element.

## Complexity

O(N log N) for N cubes up to the answer (sorting a handful of digits each). Space O(N).

## Further Thoughts

"Exactly five" is stricter than "at least five": a sixth cube with the same digits could appear later, as long
as it has the same digit count. A careful version finishes the current digit length before answering and
checks the group size is exactly 5. The answer is the same here.
