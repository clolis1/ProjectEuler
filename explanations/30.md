# Problem 30: Digit Fifth Powers

https://projecteuler.net/problem=30

**Answer:** 443839 · **Solution:** `P30.java` · **Runtime:** ~0.07 s

## Problem

Surprisingly there are only three numbers that can be written as the sum of fourth powers of their digits:

```
1634 = 1⁴ + 6⁴ + 3⁴ + 4⁴
8208 = 8⁴ + 2⁴ + 0⁴ + 8⁴
9474 = 9⁴ + 4⁴ + 7⁴ + 4⁴
```

As 1 = 1⁴ is not a sum it is not included.

The sum of these numbers is 1634 + 8208 + 9474 = 19316.

Find the sum of all the numbers that can be written as the sum of fifth powers of their digits.

## In Plain Terms

There's no clever formula, so we search — but we need to know when to stop. A digit's fifth power is at most
9⁵ = 59,049. A seven-digit number is at least a million, but seven digits' fifth powers add up to at most
413,343, which is too small. So nothing with seven or more digits can work, and we only need to check numbers
up to six digits.

## In Theory

**Bounding the search**: for a d-digit number, the digit-power sum is at most d × 9⁵, while the number is
at least 10ᵈ⁻¹. For d = 7, 7 × 59049 = 413,343 < 1,000,000, and the gap only widens. So d ≤ 6.

Six numbers qualify: 4150, 4151, 54748, 92727, 93084 and 194979, which sum to 443839.

## In Code

1. `add_digits(sum, number, depth)` recursively builds every digit string of length 2 to 6 (leading zeros
   included), carrying along the running sum of fifth powers.
2. At full length, if the digit string equals the sum written out, add it. Strings with leading zeros never
   match, so each number is counted once — at its true length. Starting at length 2 excludes 1.

## Complexity

Σ 10ᵈ for d = 2..6 ≈ 1.1 million leaves. Space O(d) recursion depth.

## Further Thoughts

Order doesn't matter in a sum, so one could enumerate digit **multisets** (non-decreasing strings) instead —
about 5,000 for six digits — and check whether the sum's digits are that multiset.
