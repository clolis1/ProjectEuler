# Problem 64: Odd Period Square Roots

https://projecteuler.net/problem=64

**Answer:** 1322 · **Solution:** `P64.java` · **Runtime:** ~0.09 s

## Problem

All square roots are periodic when written as continued fractions and can be written in the form:

```
√N = a₀ + 1/(a₁ + 1/(a₂ + 1/(a₃ + ...)))
```

For example, √23 = [4; (1, 3, 1, 8)]: after the initial 4, the block (1, 3, 1, 8) repeats indefinitely.

The first ten continued fraction representations of (irrational) square roots are:

```
√2  = [1;(2)],          period = 1
√3  = [1;(1,2)],        period = 2
√5  = [2;(4)],          period = 1
√6  = [2;(2,4)],        period = 2
√7  = [2;(1,1,1,4)],    period = 4
√8  = [2;(1,4)],        period = 2
√10 = [3;(6)],          period = 1
√11 = [3;(3,6)],        period = 2
√12 = [3;(2,6)],        period = 2
√13 = [3;(1,1,1,1,6)],  period = 5
```

Exactly four continued fractions, for N ≤ 13, have an odd period.

How many continued fractions for N ≤ 10000 have an odd period?

## In Plain Terms

Any number can be written as a whole number plus a fraction, and that fraction's flip can again be written as a
whole number plus a fraction, and so on. For square roots, the whole-number parts eventually repeat in a cycle.
We generate those parts for every non-square up to 10,000, measure how long each cycle is, and count the odd
lengths. The trick is that the whole process can be done with exact integer arithmetic.

## In Theory

The standard integer recurrence for √N (with a₀ = ⌊√N⌋, m₀ = 0, d₀ = 1):

```
mₖ₊₁ = dₖ·aₖ − mₖ
dₖ₊₁ = (N − mₖ₊₁²) / dₖ          (always exact)
aₖ₊₁ = ⌊(a₀ + mₖ₊₁) / dₖ₊₁⌋
```

The state (m, d, a) determines everything after it, so once a state repeats, the cycle has closed. For square
roots the period always ends with aₖ = 2a₀ (equivalently d = 1), which gives a simpler stopping rule.

## In Code

1. For each non-square `i` below 10,000, run the recurrence.
2. Store each (a, d, m) triplet in a list, and stop when one repeats; the list's length is the period.
3. Count the odd periods.

## Complexity

The period of √N is O(√N log N), and the repeat check scans the whole list each step, so each N costs
O(period²). Fine at this size. Space O(period).

## Further Thoughts

Stopping when aₖ = 2a₀ gives the period without storing triplets, making each N O(period). Also, `a` is
computed with `Math.sqrt(i)` in floating point; using the integer a₀ (`(a0 + m) / d`) keeps it fully exact.
