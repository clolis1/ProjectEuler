# Problem 44: Pentagon Numbers

https://projecteuler.net/problem=44

**Answer:** 5482660 · **Solution:** `P44.java` · **Runtime:** ~0.16 s

## Problem

Pentagonal numbers are generated by the formula, Pₙ = n(3n−1)/2. The first ten pentagonal numbers are:

```
1, 5, 12, 22, 35, 51, 70, 92, 117, 145, ...
```

It can be seen that P₄ + P₇ = 22 + 70 = 92 = P₈. However, their difference, 70 − 22 = 48, is not pentagonal.

Find the pair of pentagonal numbers, Pⱼ and Pₖ, for which their sum and difference are pentagonal and
D = |Pₖ − Pⱼ| is minimised; what is the value of D?

## In Plain Terms

Pentagonal numbers come from a formula, like square numbers do. We want two of them whose sum *and* difference
are also pentagonal. Generate them in order, and for each new one look back at the earlier ones: is the gap a
pentagonal number we've already seen? If so, check the sum too, using a formula that tells you whether any
number is pentagonal. The first pair found is P₁₀₂₀ and P₂₁₆₇, with difference 5,482,660.

## In Theory

**Pentagonal test**: x = n(3n − 1)/2 ⇔ 3n² − n − 2x = 0 ⇔ n = (1 + √(1 + 24x)) / 6. So x is pentagonal iff
√(1 + 24x) is an integer and (1 + √(1 + 24x)) is divisible by 6.

The search walks k upward and, for each Pₖ, checks smaller Pⱼ for a pentagonal difference (by set lookup)
and a pentagonal sum (by the formula).

The first pair found is j = 1020, k = 2167:

```
P₁₀₂₀ = 1560090    P₂₁₆₇ = 7042750
difference = 5482660 = P₁₉₁₂      sum = 8602840 = P₂₃₉₅
```

## In Code

1. Keep a `TreeSet` of pentagonal numbers, adding Pₖ for k = 4, 5, ….
2. For each new Pₖ, scan smaller Pⱼ from largest to smallest, stopping once Pⱼ < 3k − 2.
3. If Pₖ − Pⱼ is in the set and Pₖ + Pⱼ passes the discriminant test, record the difference and stop after
   this k.

## Complexity

O(k²) set lookups in the worst case up to k = 2167 — a few million operations. Space O(k).

## Further Thoughts

**The answer isn't proven minimal by this search.** Stopping at the first pair found (smallest k) doesn't
rule out a pair with larger k but a smaller difference. Project Euler accepts 5482660, and it's widely
believed to be the minimum, but a rigorous search would have to continue until consecutive pentagonal
gaps (Pₖ − Pₖ₋₁ = 3k − 2) exceed the best D found.
