# Problem 80: Square Root Digital Expansion

https://projecteuler.net/problem=80

**Answer:** 40886 · **Solution:** `P80.java` · **Runtime:** ~0.03 s

## Problem

It is well known that if the square root of a natural number is not an integer, then it is irrational. The decimal
expansion of such square roots is infinite without any repeating pattern at all.

The square root of two is 1.41421356237309504880..., and the digital sum of the first one hundred decimal digits is
475.

For the first one hundred natural numbers, find the total of the digital sums of the first one hundred decimal
digits for all the irrational square roots.

## In Plain Terms

For each of 1–100 that isn't a perfect square, work out its square root to 100 digits and add up those digits.
Ordinary computer numbers only hold about 16 digits, so the code uses the old pencil-and-paper method for square
roots, which produces one exact digit at a time, using big integers.

## In Theory

"The first one hundred decimal digits" includes the digits before the decimal point (the √2 example sums
1, 4, 1, 4, 2, …), so we need 100 significant digits.

The **digit-by-digit method**: bring down two digits of N at a time; with the current root r and remainder c, the
next digit is the largest x with (20r + x)·x ≤ c. Then c ← c − (20r + x)·x and r ← 10r + x. Every digit is exact.

Equivalently, the 100 digits of √N are the digits of ⌊√(N × 10¹⁹⁸)⌋, an **integer square root** of a big number.

## In Code

1. Skip perfect squares (`Arithmetic.isSquare`).
2. `Digits.decimalRepOfSquareRoot(i, 100)` runs the digit-by-digit method with `BigInteger` and returns the first
   100 digits as a string (no rounding).
3. Add up the digits across all 90 irrational roots.

## Complexity

O(D² ) big-number work per root for D = 100 digits, times 90 roots. Space O(D).

## Further Thoughts

`BigInteger.valueOf(N).multiply(BigInteger.TEN.pow(198)).sqrt()` (Java 9+) gives the same 100 digits in one line.
