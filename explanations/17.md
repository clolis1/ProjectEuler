# Problem 17: Number Letter Counts

https://projecteuler.net/problem=17

**Answer:** 21124 · **Solution:** `P17.java` · **Runtime:** < 0.01 s

## Problem

If the numbers 1 to 5 are written out in words: one, two, three, four, five, then there are
3 + 3 + 5 + 4 + 4 = 19 letters used in total.

If all the numbers from 1 to 1000 (one thousand) inclusive were written out in words, how many letters would
be used?

NOTE: Do not count spaces or hyphens. For example, 342 (three hundred and forty-two) contains 23 letters and
115 (one hundred and fifteen) contains 20 letters. The use of "and" when writing out numbers is in compliance
with British usage.

## In Plain Terms

English number names are built from a small set of pieces: "one" to "nineteen", the tens words ("twenty",
"thirty", …), "hundred", and "and". Break each number into those pieces, add up the letters in each piece,
and total it all from 1 to 1000. The only fiddly part is remembering the British "and" (three hundred
**and** forty-two) and that 11–19 have their own names.

## In Theory

For 1 ≤ n ≤ 999, split n = 100h + r where r is the last two digits:

```
letters(n) = letters(r)                                   (1–19 directly; 20–99 = tens word + ones word)
           + [h > 0] × (letters(h) + len("hundred"))
           + [h > 0 and r > 0] × len("and")
```

plus 11 letters for "one thousand". For example, 342 → "three" (5) + "hundred" (7) + "and" (3) +
"forty" (5) + "two" (3) = 23.

## In Code

1. `lettersInNum(x)` splits `x` into `tens_and_ones = x % 100` and `hundreds = x / 100`.
2. A switch gives letter counts for 1–19; for 20–99, one switch for the tens word and one for the ones word.
3. The hundreds switch stores letters(h) + 7 ("hundred") in one number — e.g. 10 for "onehundred".
4. Add 3 for "and" when there are both hundreds and a remainder.
5. Sum over 1–999, then add 11 for "onethousand".

## Complexity

O(n), constant work per number. Space O(1).
