# Problem 9: Special Pythagorean Triplet

https://projecteuler.net/problem=9

**Answer:** 31875000 · **Solution:** `P9.java` · **Runtime:** < 0.01 s

## Problem

A Pythagorean triplet is a set of three natural numbers, a < b < c, for which

```
a² + b² = c²
```

For example, 3² + 4² = 9 + 16 = 25 = 5².

There exists exactly one Pythagorean triplet for which a + b + c = 1000. Find the product abc.

## In Plain Terms

Right triangles with whole-number sides — like 3-4-5 — are rare, and there's a recipe that generates all
of the "basic" ones; every other one is just a basic one scaled up (6-8-10 is 3-4-5 doubled). So rather than
testing millions of combinations of a, b and c, generate the basic triangles one by one and check whether
some scaled-up copy has a perimeter of exactly 1000. It turns out 8-15-17 scaled by 25 does:
200 + 375 + 425 = 1000.

## In Theory

Every **primitive** Pythagorean triple (no common factor) comes from a pair of odd, coprime integers
u > v > 0:

```
a = uv,   b = (u² − v²)/2,   c = (u² + v²)/2
```

(This is Euclid's formula in its "odd parameters" form.) All other triples are multiples k·(a, b, c).
So we need a primitive triple whose perimeter divides 1000.

u = 5, v = 3 gives (15, 8, 17), perimeter 40, and 1000 / 40 = 25:

```
(375, 200, 425):  200² + 375² = 40000 + 140625 = 180625 = 425²
abc = 375 × 200 × 425 = 31875000
```

## In Code

1. Start from u = 3, v = 1 (the triple 3-4-5).
2. For the current primitive triple, add copies of it (`a += x`, …) while the perimeter is under 1000.
   If it lands exactly on 1000, stop.
3. Otherwise move to the next primitive triple: increase `u` by 2 until it's coprime with `v`
   (`Divisors.isRelativelyPrime`). If that triple's perimeter is already over 1000, increase `v` by 2
   and restart `u` just above it.
4. Return `a × b × c`.

## Complexity

The number of (u, v) pairs with perimeter ≤ P is O(P), and each is scaled at most P / perimeter times —
tiny for P = 1000. Space O(1).
