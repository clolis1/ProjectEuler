# Problem 82: Path Sum: Three Ways

https://projecteuler.net/problem=82

**Answer:** 260324 · **Solution:** `P82.java` · **Runtime:** < 0.01 s

## Problem

The minimal path sum in the 5 by 5 matrix below, by starting in any cell in the left column and finishing in any
cell in the right column, and only moving up, down, and right, is marked with brackets; the sum is equal to 994.

```
 131   673  [234] [103]  [18]
[201]  [96] [342]  965   150
 630   803   746   422   111
 537   699   497   121   956
 805   732   524    37   331
```

Find the minimal path sum from the left column to the right column in matrix.txt (`data/p082_matrix.txt`), a 31K
text file containing an 80 by 80 matrix.

## In Plain Terms

Now you can move up and down as well as right, and start anywhere on the left edge. Work column by column. For
each new column, first assume you entered every cell straight from the left. Then sweep down the column, letting
each cell improve on that by coming from the cell above, and sweep up, letting it come from the cell below. After
both sweeps, each cell holds the cheapest way to reach it.

## In Theory

Within one column you never want to move both up and down (that would revisit cells), so the best path into cell
(i, j) enters column j at some row and walks straight up or straight down to i. Three passes per column capture
that:

```
cost(i, j) = grid(i, j) + cost(i, j−1)                        (from the left)
cost(i, j) = min(cost(i, j), cost(i−1, j) + grid(i, j))       (downward sweep)
cost(i, j) = min(cost(i, j), cost(i+1, j) + grid(i, j))       (upward sweep)
```

The answer is the minimum over the last column.

## In Code

1. Read the matrix with `Resources.reader`.
2. Column 0's costs are just its values. For each later column, do the "from the left" and downward pass together
   (top to bottom), then the upward pass (bottom to top).
3. Return the smallest cost in column 79.

## Complexity

O(n²) — three passes over each of n columns of n cells. Space O(n²).
