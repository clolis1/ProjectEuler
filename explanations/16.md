# Problem 16: Power Digit Sum

https://projecteuler.net/problem=16

**Answer:** 1366 · **Solution:** `P16.java` · **Runtime:** < 0.01 s

## Problem

2¹⁵ = 32768 and the sum of its digits is 3 + 2 + 7 + 6 + 8 = 26.

What is the sum of the digits of the number 2¹⁰⁰⁰?

## In Plain Terms

2 multiplied by itself a thousand times is a 302-digit number — too big for an ordinary number variable,
but Java has a "big integer" type that can hold numbers of any size. Compute it, write it out as text, and
add up its digits.

## In Theory

2¹⁰⁰⁰ has ⌊1000 × log₁₀ 2⌋ + 1 = 302 digits. `BigInteger.pow` uses repeated squaring, so computing it takes
about log₂ 1000 ≈ 10 big multiplications.

## In Code

1. `new BigInteger("2").pow(1000).toString()`.
2. Add `Character.getNumericValue` of each character.

## Complexity

Dominated by the big-number multiplications — O(d²) or better for d digits — and O(d) to sum. Instant
at d = 302. Space O(d).
