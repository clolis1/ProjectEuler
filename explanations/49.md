# Problem 49: Prime Permutations

https://projecteuler.net/problem=49

**Answer:** 296962999629 · **Solution:** `P49.java` · **Runtime:** ~0.04 s

## Problem

The arithmetic sequence, 1487, 4817, 8147, in which each of the terms increases by 3330, is unusual in two
ways: (i) each of the three terms are prime, and, (ii) each of the 4-digit numbers are permutations of one
another.

There are no arithmetic sequences made up of three 1-, 2-, or 3-digit primes, exhibiting this property, but
there is one other 4-digit increasing sequence.

What 12-digit number do you form by concatenating the three terms in this sequence?

## In Plain Terms

Look at pairs of four-digit primes that use the same digits rearranged — like 1487 and 4817. If the gap between
them is d, check whether the number d further along is also a prime made of the same digits. To test "same
digits", sort each number's digits: 1487 and 4817 both become "1478". The problem gives one answer away, so we
skip it and find the other: 2969, 6299, 9629.

## In Theory

Each triple is an **arithmetic progression** a, b, 2b − a. Two numbers are digit-permutations of each other iff
their sorted-digit strings match — a "signature" that groups anagrams.

The other sequence is 2969, 6299, 9629 (common difference 3330, like the example).

## In Code

1. Put all 4-digit primes in a `TreeSet` (`Primes.getSetPrimesUpUntil(10000).tailSet(999)`).
2. For each prime `i` (skipping 1487) and each larger prime `j` with the same sorted-digit signature, check
   whether `2j − i` is prime and has the same signature.
3. Concatenate the first triple found.

## Complexity

O(P²) pairs of 4-digit primes in the worst case (P ≈ 1,061), with cheap checks. Space O(P).

## Further Thoughts

Grouping primes by signature first (a map from sorted digits to primes) means only primes within a group are
ever paired, which shrinks the work dramatically.
