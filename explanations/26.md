# Problem 26: Reciprocal Cycles

https://projecteuler.net/problem=26

**Answer:** 983 · **Solution:** `P26.java` · **Runtime:** < 0.01 s

## Problem

A unit fraction contains 1 in the numerator. The decimal representation of the unit fractions with
denominators 2 to 10 are given:

```
1/2  = 0.5
1/3  = 0.(3)
1/4  = 0.25
1/5  = 0.2
1/6  = 0.1(6)
1/7  = 0.(142857)
1/8  = 0.125
1/9  = 0.(1)
1/10 = 0.1
```

Where 0.1(6) means 0.166666..., and has a 1-digit recurring cycle. It can be seen that 1/7 has a 6-digit
recurring cycle.

Find the value of d < 1000 for which 1/d contains the longest recurring cycle in its decimal fraction part.

## In Plain Terms

When you do long division of 1 by d, you keep getting remainders, and the moment a remainder repeats, the
digits start repeating too. There are only d − 1 possible remainders, so the longest a cycle can be is d − 1.
Some primes — like 7 — actually hit that maximum; they're called "full reptend primes". So: check primes from
the top down, and the first one with a full-length cycle is the winner, since no smaller number can beat it.

## In Theory

For d coprime to 10, the cycle length of 1/d is the **multiplicative order** of 10 modulo d: the smallest
k > 0 with 10ᵏ ≡ 1 (mod d). It always divides φ(d) (Euler's totient), so it's at most d − 1, with equality only
when d is prime and 10 is a **primitive root** mod d.

Factors of 2 and 5 only add a non-repeating prefix, and composite d have shorter cycles than nearby primes, so
only primes need checking. Scanning primes downward from 997, the first with period p − 1 is 983. Any smaller
d has period ≤ d − 1 < 982, so we can stop.

## In Code

1. Get primes below 1000 with `Primes.getPrimesUpUntil`, and walk them from largest to smallest.
2. For each prime, step `r = 10r mod p` p − 1 times to land inside the cycle, then count steps until `r`
   returns to the same value — that's the period.
3. Track the largest period, and stop as soon as a prime has period p − 1.

## Complexity

O(p) per prime tested, and only a handful are tested before hitting 983. Space O(n / ln n) for the prime list.
