# Problem 1: Multiples of 3 or 5

https://projecteuler.net/problem=1

**Answer:** 233168 · **Solution:** `P1.java` · **Runtime:** < 0.01 s

## Problem

If we list all the natural numbers below 10 that are multiples of 3 or 5, we get 3, 5, 6 and 9.
The sum of these multiples is 23.

Find the sum of all the multiples of 3 or 5 below 1000.

## In Plain Terms

Count from 1 up to 999, and every time you hit a number that 3 or 5 divides evenly
(3, 5, 6, 9, 10, 12, 15, …), drop it into a running total. The only subtlety is numbers like 15
or 30 that are multiples of *both* — they belong in the total once, not twice.

## In Theory

We want the sum of the set

```
S = { x : 0 < x < 1000, and x mod 3 = 0 or x mod 5 = 0 }
```

Checking every number works fine at this size, but there's also a closed form using
**inclusion–exclusion**. The multiples of k below 1000 are k, 2k, …, mk with m = ⌊999/k⌋, and their sum is

```
k × (1 + 2 + … + m) = k × m(m+1)/2
```

Adding the multiples of 3 and of 5 counts the multiples of 15 twice, so subtract them once:

```
sum(3) + sum(5) − sum(15) = 166833 + 99500 − 33165 = 233168
```

## In Code

1. Loop `i` from 0 to 999.
2. If `i % 3 == 0 || i % 5 == 0`, add `i` to `sum`. (The `||` handles the overlap automatically —
   15 passes the test once and is added once.)
3. Print `sum`.

## Complexity

Time O(n) — one check per number below n. Space O(1).
The inclusion–exclusion formula is O(1).
