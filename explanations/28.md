# Problem 28: Number Spiral Diagonals

https://projecteuler.net/problem=28

**Answer:** 669171001 · **Solution:** `P28.java` · **Runtime:** < 0.01 s

## Problem

Starting with the number 1 and moving to the right in a clockwise direction a 5 by 5 spiral is formed as
follows:

```
21 22 23 24 25
20  7  8  9 10
19  6  1  2 11
18  5  4  3 12
17 16 15 14 13
```

It can be verified that the sum of the numbers on the diagonals is 101.

What is the sum of the numbers on the diagonals in a 1001 by 1001 spiral formed in the same way?

## In Plain Terms

Each ring of the spiral is a square, and its four corners follow a simple pattern: the top-right corner is
always an odd number squared (9, 25, 49, …), and the other three corners count backward from it in equal
steps. So the corners of every ring can be written as a formula, and adding up formulas is something algebra
does in one go — no spiral needs to be built.

## In Theory

Ring k (k = 1, 2, …) has side length 2k + 1. Its corners are

```
(2k+1)²,  (2k+1)² − 2k,  (2k+1)² − 4k,  (2k+1)² − 6k
```

which add up to 4(2k+1)² − 12k = 16k² + 4k + 4. The diagonal sum is 1 for the centre plus all rings:

```
S(n) = 1 + Σₖ₌₁ⁿ (16k² + 4k + 4)
     = 1 + 16·n(n+1)(2n+1)/6 + 4·n(n+1)/2 + 4n
     = (16n³ + 30n² + 26n)/3 + 1
```

A 1001×1001 spiral has n = 500 rings. Check with the 5×5 example (n = 2): (128 + 120 + 52)/3 + 1 = 101. ✓

## In Code

Evaluates `(8n³ + 15n² + 13n) × 2 / 3 + 1` with n = 500 in `long` arithmetic. The multiply-before-divide
ordering keeps everything an exact integer.

## Complexity

O(1). Space O(1).
