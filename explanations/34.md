# Problem 34: Digit Factorials

https://projecteuler.net/problem=34

**Answer:** 40730 · **Solution:** `P34.java` · **Runtime:** ~0.4 s

## Problem

145 is a curious number, as 1! + 4! + 5! = 1 + 24 + 120 = 145.

Find the sum of all numbers which are equal to the sum of the factorial of their digits.

Note: As 1! = 1 and 2! = 2 are not sums they are not included.

## In Plain Terms

Same idea as Problem 30, with factorials instead of fifth powers. First figure out how far to search: the
biggest a digit can contribute is 9! = 362,880. An eight-digit number is at least ten million, but eight
digits can contribute at most about 2.9 million — too small. So only numbers up to seven digits can work.
Then try them all. There turn out to be just two: 145 and 40585.

## In Theory

**Bound**: a d-digit number is ≥ 10ᵈ⁻¹ while its digit-factorial sum is ≤ d × 9!. For d = 8,
8 × 362880 = 2,903,040 < 10,000,000, so d ≤ 7. (For d = 7 the bound 2,540,160 still allows some 7-digit
numbers, so 7 must be searched.)

These numbers are called **factorions**; in base 10 they are 1, 2, 145 and 40585. Excluding 1 and 2:
145 + 40585 = 40730.

Note 0! = 1, so zeros still contribute.

## In Code

1. `digitfactorial(sum, number, digits_remaining)` recursively builds digit strings up to 7 long, carrying the
   factorial sum (`Arithmetic.factorial`).
2. When the string is used up, add it if it's at least two digits and equals its own sum.
3. The extra branch at the start (when `number` is empty) lets the recursion also produce shorter strings.

## Complexity

About 10⁷ leaves for 7-digit strings — the bulk of the runtime. Space O(7) recursion depth.

## Further Thoughts

As in Problem 30, enumerating digit **multisets** instead of strings reduces the search to about 11,000
cases, since the sum doesn't depend on digit order.
