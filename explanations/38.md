# Problem 38: Pandigital Multiples

https://projecteuler.net/problem=38

**Answer:** 932718654 · **Solution:** `P38.java` · **Runtime:** < 0.01 s

## Problem

Take the number 192 and multiply it by each of 1, 2, and 3:

```
192 × 1 = 192
192 × 2 = 384
192 × 3 = 576
```

By concatenating each product we get the 1 to 9 pandigital, 192384576. We will call 192384576 the
concatenated product of 192 and (1,2,3).

The same can be achieved by starting with 9 and multiplying by 1, 2, 3, 4, and 5, giving the pandigital,
918273645, which is the concatenated product of 9 and (1,2,3,4,5).

What is the largest 1 to 9 pandigital 9-digit number that can be formed as the concatenated product of an
integer with (1,2, ... , n) where n > 1?

## In Plain Terms

Pick a starting number, write it down, then write its double after it, then its triple, and so on until you
have nine digits. If those nine digits are exactly 1 to 9, it's a hit. Only a few shapes can produce exactly
nine digits — like a four-digit number followed by its five-digit double — so only those ranges need checking.

## In Theory

The concatenation has to be exactly 9 digits. Splitting by the starting number's length:

```
1 digit,  n = 5 or 9     (9 → 918273645)
2 digits, n = 4          2+2+2+3 digits: needs 3x < 100 ≤ 4x → x in 25..33
3 digits, n = 3          3+3+3: needs 3x < 1000 → x in 100..333
4 digits, n = 2          4+5: needs 2x ≥ 10000 → x in 5000..9999
```

The answer must start with 9 to beat 918273645, which points at the 4-digit case: 9327 → 9327 | 18654 =
932718654.

## In Code

1. Seed a `TreeSet` with the example 192384576.
2. Loop over the three ranges above (2-, 3- and 4-digit starting numbers), build the concatenation, and keep it
   if `Digits.is1To9Pandigital`.
3. Return the set's largest element.

## Complexity

A few thousand candidates, each a constant-size string check. Space O(1).

## Further Thoughts

The 1-digit case isn't searched; it's safe only because its best result, 918273645, is smaller than the
answer. Adding `x = 1..9` would make the search complete.
